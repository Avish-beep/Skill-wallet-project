## 2. Reporting a Vulnerability or Security Concern

We take data privacy, credential protection, and web security seriously. If you discover a security vulnerability or accidental exposure of sensitive information in this repository, please report it responsibly:

1. **GitHub Security Advisories (Recommended):**
   Submit a private report through the [GitHub Security Advisory portal](https://github.com/Avish-beep/Skill-wallet-project/security/advisories/new).
2. **Issue Tracker (For non-sensitive inquiries):**
   If the advisory portal is unavailable, please open a confidential or flagged issue at:
   [https://github.com/Avish-beep/Skill-wallet-project/issues](https://github.com/Avish-beep/Skill-wallet-project/issues).

Please provide:
- A description of the vulnerability or data exposure.
- Specific file paths, commit hashes, or URLs involved.
- Steps to reproduce or remediate the issue.

We will review the report promptly and take corrective action within 48 to 72 hours.

---

## 3. Data Privacy & Confidentiality Rules

Contributors must strictly observe the following confidentiality guidelines:

- **Never Commit Secrets:** Do not commit API tokens, private keys, `.env` files, browser profiles, session cookies, or service credentials.
- **Student Data Privacy:** This repository contains only anonymized, aggregated student survey data. Never commit personally identifiable information (PII), student names, institutional registration IDs, contact details, or private academic transcripts.
- **Dependency Auditing:** Keep all npm and Python dependencies scanned and updated against known CVEs.
