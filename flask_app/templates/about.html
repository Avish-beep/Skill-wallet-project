Project Information

About the Study & System Architecture

SkillWallet Applied Analytics Project

Project Title: Analysing Mental Health in Student Ecosystem

Domain: Healthcare & Higher Education Analytics

Course/Module: Data Analytics with Tableau (VIP Program)

Curriculum Scope: 8 Epics • 14 Total Tasks • 9 Subtasks

Technology Stack

  • Tableau Desktop 2026.1: Visual analytics, calculated fields, interactive dashboards, and narrative story points.
  • Python 3.11.9: Data preprocessing, statistical validation, and ETL pipelines using pandas and numpy.
  • Flask 3.1.3: Lightweight web server embedding visual assets via Tableau Web Component API v3.
  • GitHub: Version control, branch management, and collaborative portfolio hosting.

Methodology & Ethics

All student records are completely anonymized with synthetic surrogate keys (STD_0001 to STD_0101). Zero synthetic bias or artificial records were injected. Missing values in demographic fields were imputed using cohort medians, and categorical ordinal scales were standardized to preserve survey fidelity.
