# Tableau Desktop 2026.1 Setup & Publishing Guide
## Project: Analysing Mental Health in Student Ecosystem

This guide provides the exact sequence of actions to build the workbook in **Tableau Desktop 2026.1** and publish it to **Tableau Public**.

---

### Step 1: Open Tableau Desktop & Connect to Data
1. Launch **Tableau Desktop 2026.1** from the Windows Start menu or navigate to:
   `"C:\Program Files\Tableau\Tableau 2026.1\bin\tableau.exe"`
2. In the left-hand **Connect** panel under *To a File*, select **Text file**.
3. Browse to the validated processed dataset location:
   `C:\Skillwallet\data\processed\student_mental_health_processed.csv`
4. Verify the data preview:
   - Total Fields: 23
   - Rows: 101
   - Ensure `User_ID` is read as Text, `Age` and flag fields as Integers, and `CGPA_Midpoint` as Number (decimal).
5. Click **Sheet 1** at the bottom left to enter the authoring workspace.

---

### Step 2: Create the Calculated Fields
In the Data pane, click the downward arrow next to the Search bar and choose **Create Calculated Field...** for each field:

1. **`Total Students`**:
   `COUNTD([User_ID])`
2. **`High Risk Count`**:
   `COUNTD(IF [Mental_Health_Risk] = 'High Risk' THEN [User_ID] END)`
3. **`High Risk %`**:
   `[High Risk Count] / [Total Students]`
4. **`Moderate Risk Count`**:
   `COUNTD(IF [Mental_Health_Risk] = 'Moderate Risk' THEN [User_ID] END)`
5. **`Treatment Gap Count`**:
   `COUNTD(IF [Treatment_Gap] = 'Untreated Condition' THEN [User_ID] END)`
6. **`Treatment Gap Rate %`**:
   `[Treatment Gap Count] / COUNTD(IF [Condition_Count] > 0 THEN [User_ID] END)`
7. **`Depression Rate %`**:
   `SUM([Depression_Flag]) / [Total Students]`
8. **`Anxiety Rate %`**:
   `SUM([Anxiety_Flag]) / [Total Students]`
9. **`Panic Attack Rate %`**:
   `SUM([Panic_Attack_Flag]) / [Total Students]`

---

### Step 3: Open the Built Workbook
Alternatively, simply open the pre-built, verified Tableau workbook file generated by the project pipeline:
```powershell
& "C:\Program Files\Tableau\Tableau 2026.1\bin\tableau.exe" "C:\Skillwallet\tableau\student_mental_health_visualizations.twb"
```
This workbook automatically connects to `data/processed/student_mental_health_processed.csv` and contains all 10 worksheets and 2 dashboards.

---

### Step 4: Publish to Tableau Public
1. In Tableau Desktop navigation menu, click: **Server** &rarr; **Tableau Public** &rarr; **Save to Tableau Public As...**
2. Enter your friend's Tableau Public credentials when prompted.
3. Set the workbook title: `Analysing Mental Health in Student Ecosystem`.
4. Click **Save**.
5. Copy the generated Tableau Public URL and document it in project records.
